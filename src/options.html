Use My Profile Account

Settings for this Edge profile. Changes save automatically.

Your organization manages some of these settings.

Account

Edge profile account –
Sign-in sessions

Opens Microsoft’s sign-out page for this profile. Your Edge profile stays signed in. A site may need its own sign-out; this does not clear all cookies or cached tokens.

Sign-in behavior

New work sign-ins use this profile’s account, replacing a site’s account hint and skipping its account selector.

Sign-in is silent when Microsoft can use an existing session. Passwords, MFA and consent may still be required. Existing website sessions and account-specific background renewals are not switched.

Excluded sites

Leave blank for normal use. Sign-ins that start from or return to these sites are left alone. One per line; subdomains are included. Up to 100 sites.

Other settings that affect sign-in

  • Sign in to this Edge profile with your work or school account (Settings › Profiles). That’s the account this extension uses. It only chooses the account, so you may still be asked for a password or MFA.
  • Which profile a site opens in. Automatic profile switching (Settings › Profiles), and Profile preferences for sites and Default profile for external links (Settings › Profiles › Profile preferences), can open a site in another profile. It then signs in with that profile’s account.
  • Site access (Extensions › Details) must allow Microsoft’s sign-in pages. The extension never runs in InPrivate windows.
