Sign-in sessions

Signs you out of Microsoft sign-in in this Edge profile, and out of sites that support it, so they sign in again with this profile’s account. Your Edge profile stays signed in. With several accounts signed in, Microsoft asks which to sign out.

Excluded sites

Sign-ins that start from or return to these sites are left alone. One per line, for example dev.azure.com. Subdomains are included.

Other settings that affect sign-in

  • Sign in to this Edge profile with your work or school account (Settings › Profiles). That’s the account this extension uses. It only chooses the account, so you may still be asked for a password or MFA.
  • Which profile a site opens in. Automatic profile switching (Settings › Profiles), and Profile preferences for sites and Default profile for external links (Settings › Profiles › Profile preferences), can open a site in another profile. It then signs in with that profile’s account.
  • You don’t need to add this account to Windows (Settings › Accounts › Access work or school) for this extension. Doing that registers this PC with the account’s organization and can enroll it in their device management.
  • Site access (Extensions › Details) must allow Microsoft’s sign-in pages. The extension never runs in InPrivate windows.
