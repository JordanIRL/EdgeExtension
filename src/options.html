Excluded sites

Sign-ins that start from or return to these sites are left alone. One per line, for example dev.azure.com. Subdomains are included.

Edge settings that also matter

  • Automatic profile switching (edge://settings/profiles/multiProfileSettings) can move a Microsoft site into another profile before this extension runs. Turn it off, or set those sites to stay in the current profile.
  • For sign-in without a password prompt, the account should also be added to Windows under Settings › Accounts › Access work or school.
  • This extension picks the account, but apps that sign in through Windows directly (not the sign-in page) aren’t affected.
